## 一、整体风格基调（所有图必须保持一致）

为了保证整套图标的视觉统一，以下是**全局风格关键词**，每张图的 prompt 里都要带上：

> **中文描述**：可爱卡通插画风、柔和粉调、奶油质感、圆角、轻微立体、细腻高光、淡淡投影、马卡龙配色、Q 版萌系、扁平化但带一点点 3D 厚度，整体甜美少女恋爱氛围。

> **English Style Tag（推荐拼接到所有 prompt 末尾）**：
> `cute kawaii cartoon illustration, soft pastel pink theme, romantic cozy mood, rounded shapes, slight 3D depth with soft shading, glossy creamy highlight, gentle drop shadow, macaron color palette (#fff1f2 #fb7185 #f9a8d4 #fda4af), chibi style, flat design with subtle volume, sticker style, clean vector look, transparent background, high quality, 4k, centered composition`

> **统一负面词（Negative prompt）**：
> `realistic photo, dark, scary, harsh shadow, complex background, text, watermark, low quality, blurry, deformed, extra limbs, gore, horror`

> **建议尺寸**：所有图标 1024×1024 PNG 透明背景；标题 logo 1920×1080 横版透明 PNG；棋子人物建议 768×1024 竖版透明 PNG。

## 四、棋子角色（重点 · 6 张图）

> ⚠️ **重要**：男女两个小人必须保持**完全相同的角色设定 / 头身比例 / 画风 / 视角 / 大小 / 透视**，三个状态之间只改变腿部姿势，**身体、头部、表情、配色、阴影都不能变**，否则交替播放时会"抖动"。
>
> 建议先用同一个 prompt 生成"站立"主图，再用 **图生图 / inpainting** 改腿部，效果最稳。

---

## 五、行走动画对接说明（开发参考）

把生成好的 6 张棋子图按以下命名保存：

```
piece_girl_stand.png   // 站立
piece_girl_left.png    // 伸左腿
piece_girl_right.png   // 伸右腿
piece_boy_stand.png    // 站立
piece_boy_left.png     // 伸左腿
piece_boy_right.png    // 伸右腿
```

**动画播放规则**：
- 棋子**未移动**（idle）：显示 `*_stand.png`
- 棋子**移动中**：以 `left → stand → right → stand → left → ...` 的顺序循环切换，每帧约 150~200ms（与代码里 `await new Promise(res=>setTimeout(res,300))` 的 300ms 一步移动节奏匹配，可视情况微调）
- 移动结束：回到 `*_stand.png`

伪代码示意（未来在 `演示2.html` 内替换 `👧 / 👦` 时可参考）：

```js
const walkFrames = ['stand', 'left', 'stand', 'right']
let frameIdx = 0
const tick = () => {
  imgEl.src = `piece_girl_${walkFrames[frameIdx % 4]}.png`
  frameIdx++
}
const timer = setInterval(tick, 150)
// 移动结束后 clearInterval(timer) 并设回 stand
```
