# 演示2.html 界面线稿图

本页面是一个基于 Vue 3 + Tailwind 的「恋爱飞行棋」H5 互动小游戏，移动端竖屏布局，包含首页模式选择、游戏主界面（飞行棋盘 + 骰子 + 操作按钮），以及 4 种弹窗（普通任务 / 对抗任务 / 比例设置 / 主题选择）。下面分别画出各状态下的界面线稿。

---

## 状态1：首页（view === 'home'）

```
┌──────────────────────────────────────────┐
│                                          │  ← 顶部留白 pt-10
│                                          │
│            恋  爱  飞  行  棋             │  ← 主标题 (h1, 玫红色, 5xl)
│            情 侣 互 动 小 游 戏            │  ← 副标题 (rose-300, xs)
│                                          │
│                                          │
│   ┌──────────────────────────────────┐   │
│   │  💞   情侣飞行棋             ❯  │   │  ← 模式按钮 1 (love)
│   └──────────────────────────────────┘   │
│                                          │
│   ┌──────────────────────────────────┐   │
│   │  🔞   羞羞飞行棋             ❯  │   │  ← 模式按钮 2 (shy)
│   └──────────────────────────────────┘   │
│                                          │
│   ┌──────────────────────────────────┐   │
│   │  ⚙️   自定义飞行棋           ❯  │   │  ← 模式按钮 3 (custom)
│   └──────────────────────────────────┘   │
│                                          │
│                                          │
└──────────────────────────────────────────┘
       max-w-md, 居中, 浅粉背景 #fff1f2
```

图例 / 功能说明：
- 主标题区：`恋爱飞行棋` 大标题 + `情侣互动小游戏` 副标题。
- 模式按钮列表：垂直堆叠的 3 个白色圆角胶囊按钮，左侧 emoji 图标 + 模式名，右侧 `❯` 箭头。点击后调用 `initGame(key)` 进入游戏主界面。

```
   底部固定区：骰子水平居中 (bottom 60)
```

图例 / 功能说明：
- 顶部 header（`absolute top-4`）：左侧 `🏠` 返回首页按钮、中间当前模式 + 子主题胶囊状态条、右侧占位 div。
- 棋盘容器 `.board-container`（340×480，圆角 3rem，半透明白底）：40 个 `cell` 通过绝对定位 `left/top` 拼成一条螺旋路径——外圈（顶 7 格 → 左 8 格 → 底 6 格 → 右 6 格）+ 内圈再绕一圈到中心终点。
- 棋盘格子颜色按类型：起点 rose-500、终点 rose-600、`task` 紫、`test` 翠绿、`truth` 粉、`fight` 橙、`story` 天蓝；格子上显示编号或 `🏁`。
- 棋子：女生 `👧` 显示在 `playerPos[0]` 对应格子的左上角，男生 `👦` 显示在 `playerPos[1]` 对应格子的右下角。
- 右下浮动按钮组：`比例设置`、`切换主题`（fixed 定位，与骰子在同一底部高度）。
- 底部骰子区（fixed 水平居中，bottom 60）：圆形毛玻璃容器内放 6xl 的骰子 emoji（`initial` 时呼吸动画、`rolling` 时旋转动画、`result` 时显示 ⚀–⚅）。下方是 rose-400 的胶囊文字提示，三种文案：`女生回合 / 男生回合`、`掷骰子中...`、`掷出 N 点`。

## 状态3：普通任务弹窗（modal.show && !isFightTask）

```
       ┌── 半透明黑色遮罩 + 毛玻璃 ──┐
       │                            │
       │   ┌──────────────────┐     │
       │   │       💜          │    │  ← 任务图标 (6xl)
       │   │                   │    │     iconMap[type]: 💜💚💗🧡💙
       │   │   女生任务         │    │  ← 标题 (任务来源 + "任务")
       │   │  ─────────────    │    │
       │   │                   │    │
       │   │  对视10秒          │    │  ← 任务内容 (max-h-48 可滚动)
       │   │  (test 类型时还附   │    │
       │   │   带 失败惩罚: xx)  │    │
       │   │                   │    │
       │   │ ┌───────────────┐ │    │
       │   │ │   任务完成     │ │   │  ← 单按钮 (rose-500)
       │   │ └───────────────┘ │    │
       │   └──────────────────┘     │
       │                            │
       └────────────────────────────┘
```

图例 / 功能说明：
- 全屏遮罩 (`fixed inset-0 z-[200]`，毛玻璃 + 黑色 20% 透明)。
- 弹窗卡片：白色圆角 2.5rem，scale-up 弹入动画。
- 内容自上而下：emoji 图标 → 标题（`女生任务` / `男生任务`）→ 任务文案（可滚动）→ 一个 `任务完成` 按钮。
- 点击 `任务完成` 调用 `closeNormalModal`，关闭弹窗并切换到下一玩家回合。
- 当玩家走到第 39 格（终点）时，复用此弹窗显示 `🏆 🎉游戏胜利 — 恭喜XX抵达终点！`。

## 状态5：格子比例设置弹窗（rateModal === true）

```
       ┌── 遮罩 (黑色 60%) + 毛玻璃 ──┐
       │                              │
       │   ┌────────────────────────┐ │
       │   │     格子比例设置         │ │  ← 标题
       │   │  ────────────────────  │ │
       │   │  💜 日常任务   [ 50 ] % │ │
       │   │  💚 双人挑战   [ 20 ] % │ │  ← 5 个比例数字输入项
       │   │  💗 真心话     [ 10 ] % │ │     (label + number input)
       │   │  🧡 情侣对抗   [ 10 ] % │ │
       │   │  💙 剧情任务   [ 10 ] % │ │
       │   │                        │ │
       │   │   总和需为100%           │ │  ← 提示文字
       │   │                        │ │
       │   │ ┌──────┐  ┌──────────┐ │ │
       │   │ │ 取消  │  │ 保存生效  │ │ │  ← 操作按钮 (灰 / 玫红)
       │   │ └──────┘  └──────────┘ │ │
       │   └────────────────────────┘ │
       │                              │
       └──────────────────────────────┘
```

图例 / 功能说明：
- 标题：`格子比例设置`。
- 5 行配置项：每行 emoji + 类型名（左）+ 数字输入框 + `%`（右），分别对应 `task / test / truth / fight / story` 五种格子的占比。
- 总和校验：保存时若不为 100 则 alert 提示。
- 底部：`取消`（gray-100）+ `保存生效`（rose-500），后者会按新比例重新初始化棋盘。

## 状态6：子主题选择弹窗（themeModal === true）

```
       ┌── 遮罩 (黑色 60%) + 毛玻璃 ──┐
       │                              │
       │   ┌────────────────────────┐ │
       │   │      选择子主题          │ │  ← 标题
       │   │  ────────────────────  │ │
       │   │ ┌────────────────────┐ │ │
       │   │ │ 主题一·心动 (选中)  │ │ │  ← 选中态：rose-500 边框 + rose-50 背景
       │   │ └────────────────────┘ │ │
       │   │ ┌────────────────────┐ │ │
       │   │ │ 主题二·甜蜜         │ │ │  ← 未选中态：gray-200 边框
       │   │ └────────────────────┘ │ │
       │   │ ┌────────────────────┐ │ │
       │   │ │ 主题三·深情         │ │ │
       │   │ └────────────────────┘ │ │
       │   │                        │ │
       │   │ ┌────────────────────┐ │ │
       │   │ │       关闭           │ │ │  ← 关闭按钮 (gray-100)
       │   │ └────────────────────┘ │ │
       │   └────────────────────────┘ │
       │                              │
       └──────────────────────────────┘
```

图例 / 功能说明：
- 标题：`选择子主题`。
- 选项列表：根据当前模式 (`love` / `shy`) 动态渲染 `currentSubThemes`，love 模式有 3 项（心动/甜蜜/深情），shy 模式有 2 项（亲密/温柔）。
- 选中项：玫红色加粗边框 + 浅玫红背景；未选中项：灰色边框。
- 点击选项调用 `selectSubTheme(item)`，切换子主题并按新题库重置棋盘。
- 底部 `关闭` 按钮：仅关闭弹窗，不修改主题。
